## 1. 产品愿景与使命

### 1.1 愿景（Vision）

让每个人在合法权益受损时，都能快速、合法、有底气地采取行动。

### 1.2 使命（Mission）

把分散在政府公开渠道中的维权信息，结构化为人人可用的随身工具，降低维权门槛、提升维权效率。

### 1.3 价值观与边界

- **合法合规为先**：倡导依法维权，鼓励优先通过企业官方客服、内部举报或反馈渠道协商解决。
- **工具不代劳**：本产品是信息查询工具，不代理、不协助、不参与任何投诉或举报，不代用户提交材料。
- **真实可信**：内容仅来自政府公开渠道，标注验证日期与来源，虚假、恶意投诉由用户自担法律责任。
- **普惠易用**：面向全年龄段，大字号、大按钮、步骤清晰。

## 2. 战略定位与差异化

### 2.1 痛点分层与对应能力

| 痛点层级 | 具体表现 | 对应产品能力 | 解决版本 |
|----------|----------|--------------|----------|
| L1 找不到门 | 不知打哪个电话/找哪个部门 | 搜索 + 分类浏览 + 路径推荐 | V1.x |
| L2 不会说话 | 知打哪但不知怎么说 | 话术模板（电话版+书面版）+ 法律依据 | V1.x |
| L3 不懂流程 | 投诉后不知多久有结果、超期怎么办 | 跟进时间表 + 升级指引 | V1.x（静态） |
| L4 不会留证 | 无有效证据被驳回 | 证据管理 + 证据清单引导 | V2.0 |
| L5 打不动 | 投诉后对方敷衍石沉大海 | 效力评级 + 高层级平台推荐 | V2.0 |
| L6 不知边界 | 不知哪些能投诉、哪些走司法 | 司法途径指引 + 法律援助对接 | V3.0 |

**首版聚焦 L1-L2，V2.0 解决 L3-L4，V3.0 解决 L5-L6。**

### 2.2 竞争差异化

- **全链路**：找渠道 → 写话术 → 跟流程，而非单部门电话簿。
- **零成本离线**：纯本地，无网络/无费用可用。
- **透明可信**：用户可见匹配关键词，结果可溯源。
- **合规稳健**：信息工具定位清晰，备案边界明确。

### 3.2 V1.0 首发版（已发布）

**核心命题**：验证「搜索 → 渠道 → 话术」基础闭环。

**关键功能**：关键词搜索、122 条渠道详情、18 个高层级平台、19 套话术、五大分类、通用投诉信、跟进时间表、热线速查、紧急入口。

**成功标准**：用户 30 秒内从「遇到问题」到「拿到对口电话与可用话术」。

### 3.3 V1.1 正式运营版（当前，v1.1.3）

**核心命题**：从内测走向稳定运营，完善文档与合规基线。

**关键交付**：去除内测标识、版本号升至 v1.1.2、三大文档大厂规范刷新、备案合规备注、代码质量（主包未使用文件清零）。

### 3.4 V1.5 体验完善版（首版后 2-3 周）

**核心命题**：把基础体验打磨到「顺手、好用、愿意推荐」。

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 搜索日志分析与标签优化 | 匿名收集搜索词，分析未命中，持续补标签/同义词 | P0 |
| 收藏分组管理 | 自定义分组（如「我的物业维权」） | P1 |
| 浏览历史 | 最近浏览回查 | P1 |
| 话术占位符填写 | 小程序内填写生成个性化话术 | P0 |
| 分享功能 | 渠道/话术分享微信 | P1 |
| 离线模式优化 | 无网全部可用 | P1 |
| 数据更新提示 | 展示「本次更新了什么」 | P2 |
| 媒体曝光路径 | 新增「媒体曝光」第四条维权路径（舆论监督/社会监督），定义为独立于「企业投诉→监管投诉→法律途径」之外的并行监督路径，明确适用前提、与官方路径双轨并行关系、合规边界与投送指引 | P1 |
| 投诉所需材料清单 | 渠道/话术详情增加「所需材料清单 + 自检表」，按场景给出必带/建议材料，解决"知道怎么投诉却不知准备什么" | P1 |

**关键改进**：搜索命中率 80% → 90%+；占位符填写免手动改【】；搜索日志为 V2.0 AI 积累数据。

### 3.5 V2.0 智能升级（首版后 2-3 月）

**核心命题**：从「工具」升级为「助手」——用户描述问题，AI 给出完整方案。

- **AI 智能问答**：首页新增入口，自然语言 → 结构化维权方案（渠道 + 话术 + 流程 + 时限）。
- **投诉进度管理**：complaint_ticket 启用，工具箱「我的投诉」入口显现。
- **证据管理**：evidence 启用，话术详情「添加证据」显现。
- **话术定制生成**：script_type 扩展（template/ai_generated/custom）。
- **效力评级可视化**：channel 预留字段聚合展示。
- **技术底座**：微信云开发（云函数/云数据库/云存储）+ 大模型 API（豆包/通义千问，自选厂商/协议/模型）。

### 3.6 V2.5 渠道效力与多城市（4-6 月）

- **多城市支持**：channel 预留 city_code，默认 national/sichuan/chengdu → 扩展至全国。
- **渠道效力反馈**：channel_feedback 启用，用户实测成功率聚合。
- **用户反馈机制**：反馈闭环驱动数据质量。

### 3.7 V3.0 平台化（持续）

- **全国城市覆盖**：全量城市数据。
- **内容自动更新**：监控政府官网变更，自动更新渠道/热线。
- **数据洞察平台**：投诉趋势、渠道效力洞察（运营侧）。
- **开放 API**：Restful API + API Key，赋能第三方（合规场景）。
- **司法途径指引 + 法律援助对接**：解决 L6 边界认知。
- **多端发布**：在微信小程序基础上评估 H5 / PC / APP 等多端形态，技术架构预留跨端适配（Taro / uni-app），当前仍以微信小程序为唯一优先平台。
- **支付与增值服务**：order/payment 能力预留，支撑合规增值场景（如深度报告、专家咨询），需通过合规评估后启动。

> **规划中（V3.0 平台化）**：支付与增值服务、多端发布已纳入远期规划，当前微信小程序优先，架构预留扩展能力。

## 4. 能力演进矩阵（含阶段退出标准）

| 能力 | V1.0/V1.1 | V1.5 | V2.0 | V2.5 | V3.0 |

**阶段退出标准（Exit Criteria）**：

- **V1.1 退出**：搜索首条命中率 ≥ 80%、冷启动 < 2s、隐私合规零 PII、微信审核一次通过、文档基线齐备。
- **V1.5 退出**：搜索命中率 ≥ 90%、占位符填写闭环、分享可用、离线全功能验证通过。
- **V2.0 退出**：AI 问答 POC 准确率达标、云开发上线、用户登录合规（隐私政策 + 授权）、证据/进度可用。
- **V3.0 退出**：多端至少一种新形态灰度、开放 API 限流鉴权就绪、内容自动更新监控覆盖核心渠道。

- **Build vs Buy**：AI 能力采用大模型 API（买），核心数据管线自研（build）；CMS 在 V2.0 评估采购 vs 自研。

## 7. 治理与合规

| 维度 | 策略 |
|------|------|
| 内容治理 | 仅政府公开来源，标注验证日期；热线变更 12 条已对照 |
| 合规边界 | 信息工具定位，不代投诉；备案备注明确免责与虚假投诉责任 |
| 隐私治理 | 当前无个人信息收集；V2.0 登录需明确授权 + 隐私政策 |
| 风险治理 | 季度合规复盘 + 热点投诉舆情监测 |
| 数据安全治理 | 本地存储前缀隔离，无 PII 上行 |

## 8. 成功度量（北极星 + 护栏）

**北极星指标**：用户从「描述问题」到「复制可用话术」的中位耗时（当前 ≤ 30s，V2.0 ≤ 20s）。

**护栏指标（不可牺牲）**：合规红线零触碰；离线可用率 100%；冷启动 < 2s。

| 指标 | 当前 | 目标（V2.0） |
|------|------|--------------|
| 北极星：问题→话术中位耗时 | ≤ 30s | ≤ 20s |
| 搜索首条命中率 | ≥ 80% | ≥ 90% |
| 无结果率 | ≤ 15% | ≤ 5% |
| 内容覆盖 | 122 渠道 / 18 平台 | 全国 + 多城市 |
| 审核通过 | 一次通过 | 一次通过 |
