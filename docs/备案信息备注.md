# 小程序备案信息备注（合规用途）

> 适用对象：微信小程序「我不能被欺负」（v1.1.3+）
> 用途：ICP 备案 / 平台类目报备「备注」字段填写内容（20–200 字）

## 备案备注正文（可直接复制）

「我不能被欺负」为个人开发者制作的生活服务类信息查询工具，帮助用户在消费过程中遇到侵权、欺诈、不公平对待时，快速查询官方投诉渠道、投诉话术及相关法律法规，了解合法维权路径。本小程序仅提供公开信息查询，不代理、不替代用户向任何机构提交材料，不参与任何投诉或举报行为，不涉及企业经营或商业服务。我们倡导依法理性维权，鼓励用户优先通过企业官方客服、内部举报或反馈渠道协商解决纠纷；如因虚假、恶意投诉造成后果，用户须自行承担相应法律责任。

## 合规要点

- **名称一致**：名称「我不能被欺负」在备注中明确对应「消费维权/反侵权」信息查询服务，使名称、服务内容、备注三者形成关联。
- **个人性质**：强调「个人开发者制作」，非公益组织、非企业运营，不涉及商业服务或经营活动。
- **定位**：生活服务/工具类信息查询工具，不提供代理服务。
- **免责**：明确不代投诉、不代举报、不替代用户提交材料，撇清平台责任。
- **合规导向**：依法维权、优先企业内部/官方渠道、虚假投诉自担法律责任。

字数约 160 字，满足 20–200 字限制。
