## 一、产品愿景与使命

### 1.1 愿景

**让每一个普通人都能高效、有理、有据地维护自身合法权益。**

在中国，消费者和公民面临的核心困境不是"没有维权渠道"，而是"渠道太分散、信息太专业、流程太复杂"。12345、12315、12305、12378、12388……数十个投诉热线散落在不同部委，普通人遇到问题时往往不知道该找谁、该怎么说、该准备什么。

维权通的终极目标，是成为**中国老百姓的"维权操作系统"**——从"遇到问题"到"问题解决"的全流程陪伴者。

### 1.2 使命

- **信息平权**：把分散在政府各部门的投诉渠道信息结构化、可检索化，让任何人都能秒级找到对口渠道
- **能力平权**：用话术模板、法律依据、证据清单降低维权的专业门槛，让不懂法的人也能写出有法律效力的投诉
- **效率平权**：用进度管理、自动提醒、升级指引，让维权不再是"打了电话就石沉大海"的被动等待
- **认知平权**：用真实案例、效力评级、战术指南，让用户了解投诉的真实效力边界和最优策略

### 1.3 产品价值观

| 价值观 | 含义 | 产品体现 |
|--------|------|----------|
| **真实** | 只收录官方渠道，不编造、不误导 | 所有信息标注来源和验证日期，已停用热线明确标注 |
| **克制** | 工具就是工具，不煽动、不导流到非官方渠道 | 不提供"付费加急""内部关系"等灰色服务 |
| **有用** | 每个功能都要能帮用户实际推进维权 | 话术可直接复制、电话可直接拨打、流程可直接照做 |
| **中立** | 不站用户也不站商家，只站法律和事实 | 话术模板基于法律条文，不鼓励夸大、诬告、过激行为 |
| **公益底色** | 维权是基本权利，不应被商业化收割 | 核心功能永久免费，增值服务谨慎探索 |

## 二、市场与用户洞察

### 2.1 市场规模

- **消费投诉**：2025年全国12315平台受理投诉举报超 3000 万件，12345热线受理量超 1 亿件
- **劳动维权**：全国劳动人事争议调解仲裁机构每年受理案件超 200 万件
- **金融消费投诉**：银保监系统每年接收银行业保险业消费投诉超 30 万件
- **政务诉求**：全国信访系统每年接收信访事项超 800 万件次

**核心结论**：维权是高频、刚需、全民性的场景。几乎每个成年人一生中都会多次遇到需要投诉维权的情况，但目前没有一款工具能覆盖"找渠道→写话术→跟进度"的完整链路。

### 2.2 竞品分析

| 竞品类型 | 代表 | 优势 | 劣势 | 维权通的差异化 |
|----------|------|------|------|----------------|
| 政府官方平台 | 12315小程序、12345小程序、国务院客户端 | 官方权威、可直接提交投诉 | 单部门视角，用户需先知道该找哪个部门；无话术指导；无跨部门路径指引 | 跨部门全景视图 + "先帮你找对门" |
| 法律电商 | 华律网、找法网、律图 | 律师资源丰富、可付费咨询 | 重法律咨询轻投诉渠道；话术模板少；商业化重（不断引导付费） | 免费工具属性 + 聚焦行政投诉路径 |
| 内容平台 | 小红书、知乎、抖音维权帖 | 真实案例多、口语化 | 信息碎片化、质量参差、无结构化检索、容易被删 | 结构化、可检索、官方信息源 |
| 通讯录类工具 | 各类"投诉电话大全"APP/小程序 | 电话收录全 | 仅罗列电话，无适用范围、无法术、无流程、无搜索 | 全链路工具，不止是电话簿 |

### 2.3 用户痛点分层

| 痛点层级 | 具体表现 | 对应产品能力 |
|----------|----------|--------------|
| **L1 找不到门** | 遇到问题不知道该打哪个电话、找哪个部门 | 搜索 + 分类浏览 + 路径推荐 |
| **L2 不会说话** | 知道打哪个电话，但不知道怎么说才能被重视 | 话术模板（电话版+书面版）+ 法律依据引用 |
| **L3 不懂流程** | 投诉后不知道多久该有结果、超期了该怎么办 | 跟进时间表 + 进度管理 + 升级指引 |
| **L4 不会留证** | 投诉时拿不出有效证据，被以"证据不足"驳回 | 证据管理 + 证据清单引导 |
| **L5 打不动** | 投诉了但对方不处理、敷衍、石沉大海 | 效力评级 + 多级联动策略 + 高层级平台推荐 |
| **L6 不知道边界** | 不知道哪些事投诉能解决、哪些必须走司法 | 效力真相 + 司法途径指引 + 法律援助对接 |

**MVP 解决 L1-L2，V2.0 解决 L3-L4，V3.0 解决 L5-L6。**

### 3.2 V1.0 MVP（已在PRD中详述）

**核心命题**：验证"搜索→渠道→话术"的基础闭环是否成立。

**关键功能**：
- 关键词搜索（本地全文检索+标签加权）
- 109+ 行业渠道详情页
- 16 个高层级平台详情
- 5 套高频场景话术模板（电话版+书面版）
- 四大分类浏览
- 通用投诉信模板
- 投诉跟进时间表（静态）
- 热线整合变更速查
- 紧急电话入口

**成功标准**：用户能在 30 秒内从"遇到问题"到"拿到对口电话和可直接使用的话术"。

### 3.3 V1.5 体验完善版（MVP 后 2-3 周）

**核心命题**：把基础体验打磨到"顺手、好用、愿意推荐"。

**新增功能**：

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 搜索日志分析与标签优化 | 后台收集用户搜索词（匿名），分析未命中词，持续补充标签和同义词 | P0 |
| 收藏夹分类管理 | 收藏的渠道和话术可自定义分组（如"我的物业维权""快递投诉专用"） | P1 |
| 浏览历史 | 最近浏览的渠道和话术，方便回查 | P1 |
| 话术占位符填写 | 话术模板中的【姓名】【电话】【金额】等占位符，用户可在小程序内填写后生成个性化话术 | P0 |
| 分享功能 | 渠道详情和话术可分享给微信好友/群 | P1 |
| 深色模式 | 支持系统深色模式适配 | P2 |
| 字体大小调节 | 中老年用户可调大字体 | P1 |
| 离线模式优化 | 确保无网络时全部功能可用（MVP已本地存储，此版优化体验） | P1 |
| 数据更新提示 | 内容更新时，小程序内展示"本次更新了什么" | P2 |

**关键改进**：
- 搜索命中率从 80% 提升到 90%+
- 话术占位符填写功能，让用户不再需要手动改【】里的内容
- 收集搜索日志，为 V2.0 的 AI 问答积累训练数据

### 3.4 V2.0 智能升级（MVP 后 2-3 个月）

**核心命题**：从"工具"升级为"助手"——用户不再需要自己搜，而是描述问题，AI 给出完整维权方案。

#### 3.4.1 AI 智能问答（核心功能）

**交互方式**：
- 首页新增"AI 维权助手"入口
- 用户用自然语言描述问题："我在淘宝买了个手机，收到后发现是翻新机，商家不给退，怎么办？"
- AI 输出结构化维权方案：

```
📋 你的维权方案

【问题诊断】
消费纠纷（涉嫌欺诈），金额较大，建议走行政投诉+司法途径双轨。

【推荐渠道（按优先级）】
1. 全国12315平台（12315）—— 市场监管投诉，首选
   → 适用：商品质量、虚假宣传、欺诈
   → 网址：https://www.12315.cn
   
2. 12345政务热线 —— 兜底转办
   → 如果12315处理不力，可同时拨打

3. 小额诉讼 —— 如果金额≤当地上年度就业人员年平均工资50%
   → 一审终审，成本低速度快

【投诉话术（已根据你的情况生成）】
电话版："你好，我要通过12315平台投诉……"
书面版：[完整书面投诉信，已填充你描述的信息]

【需要准备的证据】
□ 订单截图和支付凭证
□ 商品照片/视频（证明是翻新机）
□ 与商家聊天记录（证明拒绝退款）
□ 如有鉴定报告更佳

【时间线提醒】
□ 今天：提交12315投诉，记录投诉编号
□ 7个工作日内：关注是否受理
□ 60日内：调解期限，超期可要求终止调解通知书
□ 如调解失败：准备小额诉讼材料
```

**技术实现**：
- 基于大语言模型（如豆包/通义千问 API）
- 系统提示词中注入全部渠道数据、话术模板、法律依据
- 输出格式严格约束为结构化 JSON，前端渲染
- 关键信息（电话、网址、法律条文）从本地数据库检索，不依赖模型幻觉生成
- 模型只负责"理解用户问题→匹配渠道→组合话术→生成方案"

#### 3.4.2 投诉进度管理

**功能描述**：
- 用户投诉后，可在小程序内创建"投诉跟踪卡"
- 跟踪卡字段：投诉事项、投诉渠道、投诉编号、投诉日期、当前状态、下次跟进日期
- 根据投诉跟进时间表，自动在关键节点推送提醒（如"投诉已7个工作日，建议查询进度"）
- 状态流转：已提交 → 已受理 → 处理中 → 已解决 / 未解决（需升级）
- 未解决时，自动推荐升级渠道（如"12315调解失败，建议走小额诉讼或向国务院督查平台反映"）

**技术实现**：
- 数据存储在微信小程序云开发数据库（需用户授权登录）
- 订阅消息推送（微信小程序原生能力）
- 进度数据与用户账号绑定，多设备同步

#### 3.4.3 证据管理

**功能描述**：
- 用户可在小程序内上传维权相关证据（照片、视频、录音、截图、文档）
- 自动按投诉事项分类归档
- 生成证据清单（可导出为文本/PDF，用于投诉提交和诉讼）
- 证据时间线展示（按时间排序，便于还原事实经过）
- 敏感信息脱敏提示（如身份证号、银行卡号建议打码）

**技术实现**：
- 微信小程序云存储（图片/视频/文件）
- 录音功能（小程序原生录音 API）
- 证据与投诉跟踪卡关联

#### 3.4.4 话术定制生成

**功能描述**：
- 用户填写表单（被投诉方、问题描述、诉求、金额、时间）
- AI 基于模板生成个性化投诉话术（电话版+书面版）
- 支持"语气调节"：温和版 / 坚定版 / 强硬版（基于法律依据的强硬，非情绪化）
- 生成的话术可直接复制或保存到收藏

#### 3.4.5 效力评级可视化

**功能描述**：
- 渠道详情页新增"效力评级"模块
- 基于文档中的投诉效力评级表，展示不同被投诉对象的管用程度（星级）
- 雷达图展示：响应速度、处罚力度、执行难度、举证要求、升级空间
- 用户可查看"为什么这个渠道对这类问题管用/不管用"

### 3.5 V2.5 社区生态（MVP 后 4-6 个月）

**核心命题**：从"单人工具"升级为"互助社区"——真实案例成为最有价值的内容。

#### 3.5.1 维权案例社区

**功能描述**：
- 用户可匿名分享自己的维权经历（问题→渠道→话术→结果→耗时）
- 案例结构化标签：问题类型、投诉渠道、处理结果、耗时、金额
- 案例可被搜索和浏览（如"快递丢失+12305+成功赔偿"）
- 其他用户可点赞、收藏、评论
- 优质案例可被编辑精选，获得曝光

**内容审核**：
- 所有案例发布前经 AI 初审+人工复审
- 禁止泄露他人隐私（姓名、电话、地址需脱敏）
- 禁止诬告、诽谤、过激言论
- 禁止商业推广和引流

#### 3.5.2 维权结果反馈

**功能描述**：
- 用户使用渠道投诉后，可反馈结果（已解决/部分解决/未解决）
- 反馈数据聚合后，展示每个渠道的"用户实测成功率"
- 渠道详情页展示：官方承诺办结时限 vs 用户实际平均耗时
- 这是对官方信息的重要补充——官方说"15个工作日办结"，但用户实际等了多久？

#### 3.5.3 多城市支持

**功能描述**：
- 从四川/成都扩展到全国主要城市（首批：北京、上海、广州、深圳、杭州、武汉、西安、重庆）
- 每个城市的属地渠道（如当地12345、当地住建部门、当地公交地铁客服）
- 用户首次打开选择所在城市，默认展示该城市渠道
- 全国通用渠道始终可见

**内容策略**：
- 首批城市优先覆盖高频领域（物业、交通、消费、劳动）
- 地方渠道信息通过政府官网公开信息整理
- 建立城市内容贡献机制（用户可提交当地渠道信息，审核后收录）

#### 3.5.4 热点投诉地图

**功能描述**：
- 基于用户搜索和投诉数据，生成"热点投诉地图"
- 展示各城市/各领域的投诉热度
- 如"成都本周物业投诉热度上升30%""全国快递丢失投诉集中在双11后"
- 数据脱敏、聚合展示，不涉及个人信息

### 3.6 V3.0 平台化（长期，6个月以上）

**核心命题**：从"应用"升级为"平台"——成为维权领域的基础设施和数据枢纽。

#### 3.6.1 全国城市全覆盖

- 覆盖全国 300+ 地级市的属地投诉渠道
- 建立内容众包+审核机制，持续更新地方渠道
- 渠道信息与当地政府网站联动，自动检测变更

#### 3.6.2 内容自动更新系统

- 爬虫监控各部委和地方政府官网，自动检测热线号码、网址变更
- 变更检测到后，自动生成更新建议，人工审核后发布
- 每季度自动核验所有电话号码可达性（自动拨号测试）
- 网址有效性自动检测（HTTP 状态码监控）

#### 3.6.3 数据洞察平台

- 基于全平台用户搜索、投诉、反馈数据，生成《中国维权生态报告》
- 维度：各行业投诉量趋势、各渠道实际效力排名、各城市维权效率对比、高频问题TOP榜
- 报告可公开下载，成为媒体、学者、政策制定者的参考
- 数据脱敏处理，严格保护用户隐私

#### 3.6.4 开放 API 平台

- 向合规第三方开放渠道数据 API（如媒体、法律科技公司、政务服务平台）
- 收费模式：基础调用免费，高频调用/商业用途收费
- API 输出：渠道信息、话术模板、投诉路径推荐
- 严格审核 API 使用者，防止数据被滥用

#### 3.6.5 企业端 SaaS（探索性）

- 面向企业的"投诉处理优化"工具
- 功能：投诉预警（监测社交媒体和投诉平台上关于本企业的投诉）、投诉响应话术建议、投诉数据分析、监管合规提醒
- 与消费者端数据隔离，独立产品
- **谨慎探索**：必须确保不会利用消费者端数据为企业"对付消费者"，严格防火墙

#### 3.6.6 司法途径深度对接

- 与法律援助机构、公益律师合作，为符合条件的用户提供免费法律咨询
- 小额诉讼全流程指引（起诉状模板、立案流程、证据清单、庭审注意事项）
- 在线生成起诉状（基于用户填写的信息和模板）
- 对接法院在线立案平台（如人民法院在线服务小程序）的跳转指引

## 四、技术演进路线

### 4.1 架构演进

```
V1.0（纯前端）          V2.0（云开发）            V3.0（独立后端）
```

## 五、商业化探索

### 5.1 商业化原则

**维权通的核心是公益工具，商业化必须服务于工具的可持续性，不能伤害用户信任。**

| 原则 | 含义 |
|------|------|
| 核心功能永久免费 | 搜索、渠道、话术、分类浏览等基础功能永远免费 |
| 不做"维权灰产" | 不提供付费加急、内部关系、删帖等灰色服务 |
| 增值服务自愿 | 付费功能必须是"锦上添花"，不是"雪中送炭的刚需" |
| 透明定价 | 所有付费功能明码标价，不搞诱导消费 |
| 数据不售卖 | 用户数据绝不用于商业售卖或定向广告 |

### 5.2 可能的变现路径（按优先级排序）

#### 路径一：法律电商导流（V2.5 探索）

- 与正规律师事务所/法律援助平台合作
- 用户有诉讼需求时，推荐合作律师（标注"广告"）
- 收费模式：CPS（按案源分成）或 CPA（按有效咨询付费）
- **风险控制**：严格审核合作方资质，不承诺结果，不介入案件处理

#### 路径二：增值服务（V2.5 探索）

| 增值服务 | 定价思路 | 说明 |
|----------|----------|------|
| AI 话术定制次数 | 免费额度+付费包 | 基础模板免费，AI 深度定制每月有限免费次数，超出付费 |
| 证据云存储扩容 | 免费基础容量+付费扩容 | 免费 1GB，付费扩容到 10GB/50GB |
| 投诉进度高级提醒 | 免费基础提醒+付费高级 | 免费订阅消息提醒，付费支持短信提醒+多渠道通知 |
| 维权方案深度报告 | 单次付费 | AI 生成完整维权方案（含渠道分析、话术、证据清单、时间线），付费下载 |

#### 路径三：企业端 SaaS（V3.0 探索）

- 面向企业的投诉监测与处理工具
- 订阅制收费（按月/按年）
- 与消费者端严格数据隔离
- **谨慎推进**：需确保不会与消费者端利益冲突

#### 路径四：开放 API（V3.0）

- 向媒体、法律科技、政务平台开放渠道数据 API
- 基础调用免费，商业用途/高频调用收费
- 需严格审核 API 使用者资质

#### 路径五：内容付费（远期，谨慎）

- 《维权实战手册》《各行业投诉效力深度报告》等深度内容
- 单篇付费或会员订阅
- **前提**：内容必须有足够深度和独家价值，不能是免费内容的重组

### 5.3 不做的商业化

- ❌ 信息流广告（伤害工具属性和用户信任）
- ❌ 开屏广告（影响使用体验）
- ❌ "付费加急处理投诉"（涉嫌违规，且可能涉及诈骗）
- ❌ "内部关系渠道"（灰色地带，绝对不碰）
- ❌ 维权结果收费（如"赔偿到账后分成"，涉嫌非法经营）
- ❌ 用户数据售卖（绝对红线）

## 六、合规与风险治理

### 6.1 法律合规框架

| 合规领域 | 要求 | 产品措施 |
|----------|------|----------|
| 个人信息保护 | 遵循《个人信息保护法》 | MVP 不收集个人信息；V2.0 登录需明确授权；隐私政策透明 |
| 内容合规 | 遵循《网络安全法》《互联网信息服务管理办法》 | 所有内容来源于官方公开渠道；UGC 内容审核机制；违法内容举报入口 |
| 广告合规 | 遵循《广告法》 | 商业推广明确标注"广告"；不做虚假宣传；不承诺维权结果 |
| 法律服务边界 | 不从事有偿法律服务（无律师执业证） | AI 输出标注"仅供参考，不构成法律意见"；不代理案件；不代写法律文书收费（V2.0 话术生成是投诉模板，非法律文书） |
| 政务信息规范 | 不冒充政府官方 | 名称/简介不使用"官方""政府"；显著标注"便民信息汇总，非官方应用"；不提供在线投诉提交（仅跳转官方平台） |
| 知识产权 | 不侵犯第三方版权 | 话术模板为原创整理；法律条文为公开法律法规；引用来源标注 |

### 6.2 内容质量保障

**三级审核机制**：
1. **录入审核**：从文档提取数据时，双人交叉核验电话和网址
2. **定期核验**：每季度自动+人工核验所有电话号码和网址有效性
3. **用户反馈**：用户可举报"号码失效""网址错误"，48小时内核实处理

**变更响应**：
- 政府机构改革、热线整合等重大变更，在 7 个工作日内完成内容更新
- 已停用热线不删除，标注"已停用→替代渠道XXX"，避免用户困惑

### 6.3 用户安全保护

| 风险场景 | 保护措施 |
|----------|----------|
| 投诉过程中被二次诈骗 | 详情页显著提示"所有官方投诉渠道均免费，要求转账的都是诈骗"；96110 反诈入口常驻 |
| 个人信息泄露 | 证据上传时提示脱敏；不强制收集身份证号；数据加密存储 |
| 紧急情况误拨 | 110/119/120 按钮增加二次确认 |
| 诬告陷害风险 | 话术模板强调"如实陈述，不得捏造事实"；书面模板包含"本人承诺以上陈述属实" |
| 过激行为引导 | 所有内容强调"依法维权、理性维权"；不鼓励围堵、闹事等过激行为 |

### 6.4 危机应对预案

| 危机场景 | 应对措施 |
|----------|----------|
| 小程序被举报下架 | 准备申诉材料；同时开发 H5 版本作为备份；用户社群通知 |
| 内容错误导致用户损失 | 立即核实更正；公开致歉；如因信息错误导致直接损失，协商补偿 |
| AI 输出错误法律建议 | AI 输出始终标注"非法律意见"；建立用户反馈纠错机制；关键信息从数据库检索而非模型生成 |
| 社区出现违法内容 | 先审后发机制；AI 初审+人工复审；24小时人工巡查；违法内容立即删除并上报 |

## 十、多端战略：从一个小程序到全平台维权生态

### 10.1 为什么要多端

微信小程序是绝佳的起点（流量大、无需安装、分享方便），但它有天然的边界：
- **包体积限制**：主包2MB，数据量大了装不下
- **审核限制**：每次更新需审核，紧急修正不及时
- **能力限制**：不能后台运行、不能批量处理文件、打印体验差
- **用户局限**：不用微信的用户（如部分老年用户、海外用户）无法使用

多端战略的核心目标：**让每一个需要维权的人，无论用什么设备、什么习惯，都能方便地获取维权信息。**

### 10.2 端矩阵与定位

| 端 | 定位 | 核心用户 | 核心价值 |
|----|------|----------|----------|
| 微信小程序 | 流量入口、轻量工具 | 普通大众、微信用户 | 即用即走、分享传播 |
| H5网站 | 搜索引擎入口、跨平台 | 所有网民 | SEO可收录、无需安装、链接可分享 |
| PC网站 | 专业工具、大屏体验 | 律师、法务、记者、研究者 | 大屏数据看板、批量查询、打印排版 |
| APP（iOS/Android） | 深度用户、原生体验 | 高频维权用户、需要推送通知 | 推送提醒、离线体验、原生能力 |
| Windows EXE | 专业桌面工具 | 律师事务所、企业法务、法律援助中心 | 完全离线、本地文件操作、批量导出、系统托盘 |
| macOS/Linux | 跨平台桌面 | 开发者、设计师、Linux用户 | 同Windows EXE |

### 10.3 多端技术路线：一次开发，多端运行

**核心洞察**：维权通的核心价值在于**数据**（122+渠道、话术、法律依据）和**搜索算法**，而不在于UI。因此，将核心层（数据+搜索+业务逻辑）与UI层解耦，核心层用纯JS编写一次，所有端复用，UI层各端适配。

```
核心层（纯JS，一次开发）：
  ├── 搜索索引模块（倒排索引、分词、排序、RAG向量检索）
  ├── 数据管理模块（Repository模式，各端存储实现不同）
  ├── 业务逻辑模块（SearchService、ChannelService、ScriptService）
  └── 埋点模块（统一接口，各端上报通道不同）

UI层（各端适配）：
  ├── 小程序：WXML/WXSS原生
  ├── Web：HTML/CSS响应式（移动端+PC端）
  ├── APP：Web + Capacitor原生壳
  └── 桌面：Web + Tauri原生壳
```

**关键优势**：
- 每新增一个端，工作量主要是UI适配（1-2周），而不是重新开发
- 搜索结果在所有端完全一致（因为用同一份索引和算法）
- 数据更新一次，所有端同步更新
- 维护成本低，核心bug修复一次所有端受益

### 10.4 各端差异化功能

不同端有不同的使用场景，应提供差异化功能：

**PC网站/EXE独有功能**：
- 大屏数据看板：全国投诉渠道热力图、各领域渠道数量统计
- 批量查询：输入多个企业名称，批量查询投诉渠道
- 投诉信生成器：填写表单自动生成规范的书面投诉信，支持Word/PDF导出
- 多渠道对比：同时对比多个渠道的效力、响应速度、成功率
- 打印优化：一键打印渠道清单、话术模板、投诉信

**APP独有功能**：
- 投诉进度提醒：设置投诉后，按跟进时间表自动推送提醒（"第3天了，该跟进了"）
- 证据拍照：直接在APP内拍照存证，自动关联到投诉跟踪卡
- 离线完全可用：所有数据预装，无网络环境也能搜索浏览
- 系统分享：一键分享渠道/话术到微信、短信、邮件

**小程序独有功能**：
- 微信分享：一键分享给微信好友/群
- 订阅消息：投诉进度提醒通过微信订阅消息推送

## 十一、搜索智能化愿景：从关键词搜索到自然语言理解

### 11.1 搜索的终极形态

当前的搜索是"关键词匹配"——用户必须知道用什么词搜索。但真实用户的表达是千奇百怪的：

- "我快递被偷了" → 应匹配"快递丢失"渠道
- "话费莫名其妙被扣了" → 应匹配"运营商乱扣费"渠道
- "商家跑路了钱要不回来" → 应匹配"消费欺诈+预付卡"渠道
- "物业把我电梯停了一个礼拜" → 应匹配"物业不作为"渠道
- "老板说没钱发工资让我再等等" → 应匹配"欠薪"渠道

**搜索的终极形态**：用户说人话，系统懂意思，直接给出解决方案。

### 11.2 搜索智能化四阶段

**第一阶段：关键词提取+场景选项卡（MVP，当前已实现）**
- 330+关键词词库，正向最大匹配提取核心关键词
- 20预设场景映射，关键词组合→匹配场景→展示场景选项卡
- 轻量索引（56KB）名称匹配+关键词权重搜索
- 用户输入一大段自然语言→提取关键词→展示相关场景选项卡→用户点选
- 能处理标准关键词和常见口语，零API成本
- 局限：必须用户输入中包含词库中的关键词

**第二阶段：模糊匹配+场景引导（V1.5）**
- 拼音搜索、编辑距离、错别字纠正
- 搜索无结果时引导用户选择场景
- 首页场景化入口（"我遇到了什么问题"）
- 能处理大部分口语表达和错别字

**第三阶段：语义理解+AI问答（V2.0）**
- RAG向量检索：渠道/话术向量化，语义相似度匹配
- 大模型语义理解：自然语言→结构化查询→精准匹配
- AI问答助手：用户直接问"怎么办"，AI直接给步骤+渠道+话术
- 多轮对话澄清：AI反问获取更多信息（"哪家快递？""物品价值多少？"）
- 能处理任意自然语言描述

**第四阶段：智能路由+个性化推荐（V3.0）**
- 智能路由：根据用户问题自动推荐最佳投诉渠道组合（先A后B再C）
- 个性化推荐：基于用户历史、画像、上下文，推荐最适合的渠道
- 成功率预测：基于海量用户反馈数据，预测每个渠道的成功率
- 主动提醒：根据用户投诉进度，主动提醒下一步操作
- 从"用户找渠道"变成"系统推荐最佳方案"

### 11.3 AI在维权场景的独特价值

维权场景天然适合AI，因为：
1. **信息不对称**：用户不知道有哪些渠道、哪个最有效，AI可以整合所有信息
2. **流程复杂**：投诉涉及多个步骤、多个部门，AI可以一步步引导
3. **话术门槛**：很多人不知道怎么说才能有效投诉，AI可以生成专业话术
4. **法律知识**：用户不懂法律，AI可以解释相关法律条文
5. **情绪安抚**：维权时用户往往情绪激动，AI可以理性引导

**AI助手的核心能力**：
- 理解用户问题（自然语言→结构化）
- 推荐最佳渠道（基于效力、响应速度、成功率）
- 生成定制话术（根据用户具体情况填充模板）
- 规划投诉步骤（先做什么后做什么，时间节点）
- 解释法律依据（用大白话解释相关法律）
- 提醒跟进（按时间表推送提醒）
- 多轮澄清（反问获取关键信息）

### 11.4 搜索质量的持续优化机制

搜索质量不是一次性工程，而是持续优化的过程：

1. **数据积累**：记录所有搜索query、点击结果、后续行为（复制/拨打/收藏）
2. **无结果分析**：每周分析搜索无结果的query，人工补充标签/同义词/场景
3. **效果评估**：监控搜索成功率、首条点击率、搜索后转化率
4. **AI反馈闭环**：V2.0后，用户对AI回答的点赞/点踩用于模型微调
5. **A/B测试**：新搜索算法先小流量测试，效果好再全量
6. **用户反馈入口**：每个搜索结果页提供"这个结果有用吗？"反馈按钮

## 十二、写在最后

维权通的本质，不是一个"投诉工具"，而是一个**权利意识的启蒙器**。

当一个普通人发现"原来快递丢了不只能跟客服吵架，还可以打12305让邮政局罚快递公司的款""原来物业不作为不只能忍，还可以打12345让住建部门督办""原来老板欠薪不只能堵门，还可以在国务院客户端小程序提交欠薪线索"的时候，他/她获得的不仅是一次维权的成功，更是一种"我的权利是可以被维护的"的认知。

这种认知，比任何单次投诉的成功都更有价值。

**产品的终极成功，不是有多少人用了我们的工具，而是有多少人因为我们的工具，第一次相信——法律是有用的，渠道是通的，权利是可以被维护的。**
